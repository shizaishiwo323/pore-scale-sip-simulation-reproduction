# 复刻 Rembert 等微流控–SIP 方解石溶蚀模拟所需参数整理

> 目标：把论文中的微流控方解石溶蚀实验，转化为你自己的 SIP 数值模拟输入。这里按“实验几何 → 测量数据 → 图像参数 → 地球化学参数 → 岩石物理/SIP 模型参数”的顺序整理。

---

## 1. 这篇文章的模拟本质

论文不是直接做一个完整的 2D/3D 反应输运–电化学耦合模拟，而是一个相对简化的工作流：

```text
显微图像处理
  → 得到孔隙度 φ(t)、含水率 θ(t)、水饱和度 Sw(t)、方解石比表面积 Ss(t)

地球化学 pseudo-transport 模拟
  → 得到孔隙水电导率 σw(t)、pH(t)、溶蚀导致的孔隙度变化

等效电路 / Waxman–Smits 型岩石物理模型
  → 用 φ(t)、Sw(t)、σw(t) 计算复电导率 σ*(t)
  → 拟合唯一自由参数 CEC(t)
```

核心思想是：

- 实部电导率 `σ′` 主要受电解质电导率、孔隙度、含水/含气状态控制。
- 虚部电导率 `σ″` 主要反映方解石–水界面的极化。
- CO₂ 气泡主要通过降低 `Sw` 影响导电通道，论文中暂时没有把气泡作为独立极化界面详细建模。

## 3. SIP 测量参数

| 参数 | 论文取值 | 备注 |
|---|---:|---|
| 仪器 | Ontash & Ermac PSIP | 四电极 Wenner-α 布置。 |
| 激励电压 | ±1 V | 为提高信噪比。 |
| 参考电阻 | 1 MΩ | 论文按仪器建议设置，使其落在通道电阻 20–100% 范围。 |
| 频率范围，实验论文 | 100–1000 Hz | 每 decade 10 个点，50 Hz 和 100 Hz 因电网噪声剔除。 |
| 频率范围，建模论文描述 | 1 Hz–10 kHz | GRL 文中对连续监测范围的总结。 |
| 重点建模频率 | 2.5 Hz | GRL 论文主要用低频 2.5 Hz 的 `σ′` 和 `σ″` 做时间序列拟合。 |
| 谱采集间隔 | 约 7 min | Lab Chip 实验记录 50 个 SIP 谱。 |
| 图像采集间隔 | 30 s | 共约 600 张图像。 |

阻抗到复电导率的转换：

```math
Z^* = \frac{U^*}{I^*}
```

```math
\sigma^* = \frac{1}{k_G Z^*} = |\sigma^*|e^{-i\varphi} = \sigma' + i\sigma''
```

其中：

- `σ′`：实部 / in-phase conductivity，主要对应导电。
- `σ″`：虚部 / quadrature conductivity，主要对应极化。
- `kG`：几何系数，由空槽或 FEM 标定。

## 5. 图像处理需要提取的参数

从每一帧显微图像中分割出：

| 图像量 | 符号 | 单位 | 用途 |
|---|---|---|---|
| 方解石投影面积 | `A_CaCO3(t)` | m² | 计算方解石体积。 |
| 方解石轮廓周长 | `P_CaCO3(t)` | m | 计算近似比表面积。 |
| CO₂ 气泡投影面积 | `A_CO2(t)` | m² | 计算气泡体积、水饱和度。 |
| 通道厚度 | `h` | m | 把 2D 面积转成体积。 |
| 有效观测/电测体积 | `V` | m³ | 用于归一化孔隙度和含水率。 |

体积换算：

```math
V_{CaCO_3}(t)=h A_{CaCO_3}(t)
```

```math
V_{CO_2}(t)=h A_{CO_2}(t)
```

图像导出的岩石物理参数：

```math
\phi(t)=\frac{V - V_{CaCO_3}(t)}{V}
```

```math
\theta(t)=\frac{V - V_{CaCO_3}(t)-V_{CO_2}(t)}{V}
```

```math
S_w(t)=\frac{\theta(t)}{\phi(t)}
```

```math
S_s(t)=\frac{h P_{CaCO_3}(t)}{V_{CaCO_3}(t)\rho}
```

论文中的典型结果：

- 初始孔隙度 `φ ≈ 0.7`。
- 方解石完全溶解后 `φ → 1`。
- 初始没有气泡，所以 `Sw = 1`。
- `t ≈ 0.26 h` 后 CO₂ 气泡成核，`Sw` 开始下降。
- `t ≈ 4.26 h` 气泡突然被带走，`Sw` 跳升到约 `0.9`，不是 1，因为仍有小气泡残留。

## 6. 地球化学 pseudo-transport 模型参数

论文没有做完整 2D 反应输运，而是把体系简化成三个 batch reactor：

| 反应器 | 含义 | 作用 |
|---|---|---|
| BR1 | 反应水体 | 酸液与方解石反应。 |
| BR2 | 非反应水体 | 酸液从方解石侧边流过，不与方解石反应。 |
| BR3 | 下游混合水体 | BR1、BR2 与上一时刻残余溶液混合。 |

关键数值：

| 参数 | 取值 | 说明 |
|---|---:|---|
| 孔隙体积 | 6.39 μL | 电极间或有效测量区域孔隙体积。 |
| 初始方解石体积 | 2.61 μL | 与孔隙体积共同构成 9 μL 总有效体积。 |
| 流速 | 20.83 μL/min | 由 1.25 mL/h 换算。 |
| 溶液完全更新特征时间 | 0.307 min，约 18.4 s | `6.39 / 20.83`。 |
| 模拟时间步长 | 10 s | 每步部分替换孔隙水。 |
| 每步注入酸液体积 | 3.47 μL | 约为初始孔隙体积的 54.34%。 |
| 非反应水体比例 | 5% | BR2，拟合得到。 |
| 反应水体比例 | 95% | BR1，与方解石反应。 |
| 反应假设 | 每 10 s 达到热力学平衡 | 论文用 Damköhler/Péclet 数验证。 |
| 软件 | PHREEQC v3 | 用于溶液组成、pH、σw。 |
| 数据库 | Thermoddem | 低温水–岩反应数据库。 |
| 直接地球化学模拟时长 | 前 13 min | 气泡出现前的全饱和阶段。 |
| 13 min 之后的 `σw(t)` | 线性增加到 `σHCl` | 论文为满足整个实验的岩石物理输入而作的简化。 |

**你复刻时的取法：**

1. 先用你自己的酸液和初始溶液测 `σS0`、`σHCl`、pH。
2. 用 PHREEQC 或自己的反应模块模拟前期全饱和反应。
3. 如果你暂时不做完整两相反应输运，可以照论文处理：气泡阶段不再用 PHREEQC 精细计算，只把 `σw(t)` 从 13 min 线性推到 `σHCl`。
4. 如果你的模型可以处理 CO₂ 生成和气泡迁移，则不建议照搬线性外推，应直接计算局部水化学和气相体积分数。

## 7. SIP / 岩石物理模型参数

论文采用部分饱和条件下扩展的 Waxman–Smits 型等效电路模型：

```math
\sigma' = \phi^m S_w^n \left(\sigma_w + \beta \frac{Q_v}{S_w}\right)
```

```math
\sigma'' = \phi^m S_w^{n-1} \lambda Q_v
```

其中：

```math
Q_v = \frac{1-\phi}{\phi}\rho CEC
```

参数表：

| 参数 | 论文取值 | 单位 | 说明 / 取法 |
|---|---:|---|---|
| `φ(t)` | 图像处理得到 | - | 不作为拟合参数。 |
| `Sw(t)` | 图像处理得到 | - | 气泡影响主要通过这个量进入模型。 |
| `σw(t)` | 地球化学模拟得到 | S/m | 背景电解质电导率，关键输入。 |
| `m` | 1 | - | 胶结指数；论文用 EIDORS 发现流线近似平行，因此固定为 1。 |
| `n` | 2 | - | 饱和指数；采用标准值。 |
| `ρ` | 2710 | kg/m³ | 方解石密度。 |
| `βH+0` | `36.63 × 10^-8` | m² s⁻¹ V⁻¹ | H⁺ 极限迁移率。 |
| `βCa2+0` | `6.24 × 10^-8` | m² s⁻¹ V⁻¹ | Ca²⁺ 极限迁移率。 |
| `γH+` | `0.967 ± 0.005` | - | PHREEQC 活度系数。 |
| `γCa2+` | `0.738 ± 0.011` | - | PHREEQC 活度系数。 |
| `β` | `19.98 × 10^-8` | m² s⁻¹ V⁻¹ | H⁺ 和 Ca²⁺ 修正迁移率均值。 |
| `α` | 6 | - | `λ = β/α`。 |
| `λ` | `≈ 3.33 × 10^-8` | m² s⁻¹ V⁻¹ | 极化迁移率项。 |
| `CEC(t)` | 唯一拟合参数 | mEq/g | 用 `σ′` 和 `σ″` 同时反演。 |

`β` 的取法：

```math
\beta = \frac{1}{2}\left(\gamma_{H^+}\beta^0_{H^+}+\gamma_{Ca^{2+}}\beta^0_{Ca^{2+}}\right)
```

`λ` 的取法：

```math
\lambda = \frac{\beta}{\alpha}, \quad \alpha = 6
```

## 8. 背景电导、背景电解质电导率怎么取

这里要区分三个“电导”概念。

### 8.1 仪器/空槽背景

用于检查电极和几何系数：

- 用 NaCl 标准溶液充满空通道。
- 介质不含方解石，理论上几乎不产生极化。
- 检查 `σ′` 是否接近 NaCl 溶液实测电导率，`σ″` 是否接近 0。
- 由此验证 `kG`、电极极化、接触阻抗和系统噪声。

### 8.2 初始背景电解质电导率 `σS0`

这是方解石未开始溶蚀、通道被 S0 溶液饱和时的孔隙水电导率。

论文取值：

- GRL 建模文中：`σS0 = 0.01 S/m`。
- Lab Chip 实验文中：`σS0 = 0.013 S/m`。

实际复刻建议：

```text
不要机械照搬 0.01 或 0.013 S/m，优先使用你自己配制 S0 溶液的电导率实测值。
```

### 8.3 动态孔隙水电导率 `σw(t)`

这是岩石物理模型真正需要的背景电解质电导率。

取法：

1. 初始时刻：`σw(0) = σS0`。
2. 前 13 min：用 PHREEQC pseudo-transport 计算 BR3 中混合溶液的电导率。
3. 13 min 之后：论文简化为线性增加，最终达到 `σHCl = 0.44 S/m`。
4. 如果你做完整反应输运，应直接用每个时间步、每个位置的电解质组成计算局部电导率，再空间平均或进入 FEM。

## 9. 背景/材料电导率在数值模型中的推荐设置

如果你的 SIP 模型是有限元或网格模型，可以这样设置：

| 区域 | 推荐电导率设置 | 说明 |
|---|---|---|
| 孔隙水 / 酸液 | `σw(t)` | 最关键输入，随时间变化。 |
| 方解石固体体积 | 很低或近似绝缘 | 论文的极化不是通过给方解石一个高体电导来表示，而是通过 `Qv/CEC` 表示界面效应。 |
| CO₂ 气泡 | 近似绝缘 | 主要通过减少 `Sw` 和导电连通通道影响 `σ′`。 |
| PDMS | 绝缘 | 一般不进入电流计算域。 |
| 玻璃基底 | 绝缘 | 一般不进入电流计算域。 |
| 金电极 | 理想电极边界或高电导体 | 通常作为边界条件处理。 |

**注意：**如果你的 SIP 程序不能直接输入 Waxman–Smits 模型，而是需要每个网格的复电导率，那么可以先用上面的公式计算每个时间步的等效 `σ′(t)` 和 `σ″(t)`，再赋值给有效介质区域。

## 10. CEC 的拟合方式

论文把 `CEC(t)` 作为唯一自由参数，同时拟合实部和虚部：

```math
r(CEC,t)=|\sigma'_{mod}(CEC,t)-\sigma'_{dat}(t)|+\alpha |\sigma''_{mod}(CEC,t)-\sigma''_{dat}(t)|
```

其中 `α = 6`，用于让 `σ′` 和 `σ″` 的残差权重相对均衡。

拟合后：

- 用一阶 Savitzky–Golay 滤波平滑 `CEC(t)`。
- 再用平滑后的 `CEC(t)` 重新计算 `σ′mod(t)` 和 `σ″mod(t)`。
- 用 MAE 评价模型与数据的误差。

论文中 CEC 的典型范围：

- 大部分时间：`0.01–0.11 mEq/g`。
- 约 `t = 1.78 h` 达到 `0.1 mEq/g`。
- 后期最高约 `0.28 mEq/g`。
- 方解石完全溶解后降为 0。

## 12. 推荐复刻流程

1. **先复刻实验测量转换**  
   用 `Z* → σ*` 公式检查你的 SIP 数据是否能得到合理的 `σ′` 和 `σ″`。

2. **用空槽标准溶液验证背景**  
   用 NaCl 或已知电导率溶液测空通道，确认 `σ′ ≈ σw`，`σ″ ≈ 0`。

3. **处理图像**  
   得到 `φ(t)`、`Sw(t)`、`Ss(t)`，这是后面模型是否合理的关键。

4. **给出 `σw(t)`**  
   最简单版本可以采用：

   ```text
   σw(0) = σS0
   前 13 min 用 PHREEQC 或经验曲线快速升高
   13 min 后线性升高到 σHCl
   ```

5. **计算模型响应**  
   使用 Waxman–Smits 型公式计算 `σ′mod(t)`、`σ″mod(t)`。

6. **反演 CEC(t)**  
   每个时间点搜索一个 `CEC`，最小化 `σ′` 和 `σ″` 的联合残差。

7. **对比 `CEC(t)` 与 `Ss(t)`**  
   如果二者趋势相似，说明你复刻到了论文的主要结论：界面极化与方解石反应表面积/CEC 演化相关。

---

## 13. 需要特别注意的地方

- 论文中的 `σw(t)` 不是直接测出来的，而是地球化学模拟给出的背景电解质电导率。
- `σ′(t)` 是仪器测到的整体等效实部电导率，不等于 `σw(t)`。
- 气泡不是简单噪声，它会显著降低水饱和度和导电通道，所以必须进入 `Sw(t)`。
- 方解石的极化贡献主要通过 `Qv` 和 `CEC` 进入，而不是把方解石体电导率设得很大。
- 论文采用单频 2.5 Hz 做主要拟合；如果你要复刻整个频谱，则需要引入频率依赖模型，例如 Cole–Cole、Pelton 或更细的界面极化模型。
- 这篇文章的模型是“现象学 + 参数少”的模型，不是严格的机理级反应输运–电化学模型。

## 14. 一句话版参数策略

复刻时最关键的是：

```text
用图像给 φ(t) 和 Sw(t)，用 PHREEQC/实测给 σw(t)，固定 m=1、n=2、β=19.98e-8、λ=β/6，只拟合 CEC(t)，再用 Waxman–Smits 型公式计算 σ′ 和 σ″。
```
