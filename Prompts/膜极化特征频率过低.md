特征频率过低的原因：
你说得对，`Zdc` 偏小主要解释幅值，不足以解释峰位。**我刚刚专门把特征频率拆出来算了一下，根因更具体：我们当前 pnextract 的膜极化有效最短孔喉长度被截断在 `0.7 um`，而 Niu 论文膜曲线的特征频率需要约 `0.13 um` 的有效膜长度。**

膜模型里单个 throat 的峰位近似由：

```text
tau_m = L^2 / 4D
omega * tau_m ≈ 0.906 处 C_m'' 达峰
f_peak ≈ 0.906 * 4D / (2π L^2)
```

用 `D = 1.3e-9 m2/s` 反算：

```text
我们的膜峰 ~10 Hz       -> 等效 L ≈ 8.66 um
Niu 膜峰 ~4.64e4 Hz    -> 等效 L ≈ 0.127 um
当前网络最短 L = 0.7 um -> 单 throat 最高峰位也只有约 1.5 kHz
```

所以现在的核心不是平均长度。平均长度确实接近：

```text
Niu Figure 4 throat VW mean: 26.84 um
Our pnextract throat VW mean: 31.30 um
```

但膜极化的高频峰不是平均 throat 控制的，而是**极短 narrow throat tail** 控制的。论文 Figure 4 里有一批亚微米孔喉长度，1% 分位大约 `0.155 um`，这正好能把峰推到 `10^4-10^5 Hz`。而我们当前 contact-split 网络的最小长度是：

```text
min L = 0.7 um
```

这相当于把所有更短的 `0.1-0.5 um` 有效膜区都抹掉了。因为频率按 `1/L^2` 缩放，`0.7 um` 和 `0.127 um` 的差别会导致：

```text
(0.7 / 0.127)^2 ≈ 30x
```

也就是说，单就最短长度截断，就会把可达到的膜特征频率压低几十倍。

我还算了当前网络在不同频率下是谁贡献膜项：

```text
10 Hz 时：2-10 um throat 贡献约 66%
46 kHz 时：<1 um throat 贡献约 58%，但这些 throat 最短也只有 0.7 um，已经过了自己的峰，在衰减尾部
```

所以我们的谱峰自然落在 `2-10 um` 这批 throat 对应的低频段，而不是论文中亚微米 throat 对应的中高频段。

为什么那张分布图看起来还不错？因为它验证的是整体 `f(L)` 和平均值，但没有足够暴露**亚微米短孔喉尾部**。在 log 图上，整体主峰和均值对上了，但膜极化峰位对 `L` 的平方极端敏感，`0.1 um` 和 `1 um` 不是小差别，是 `100x` 频率差别。

所以只盯特征频率的话，我现在的结论是：

**峰位对应不上，主要是当前 contact-split/pnextract 输出的 throat length 下限和短孔喉尾部分布不对。我们缺少 Niu 膜极化曲线所需要的 `~0.1 um` 级有效 narrow-throat length，而当前网络最短只有 `0.7 um`，导致膜极化特征频率必然偏低。**
