| Directory | Contents |
| --- | --- |
| `ac2d_microfluidic/` | 2-D microfluidic SIP mechanism spectra and time-response plots. |
| `ac3d_gpu_diagnostics/` | 3-D AC3D GPU/FFT convergence, benchmark, and reproduced Figure 6-8 sweep plots. |
| `berea_pore_network/` | Berea pore-network renderings from pnextract and styling variants. |
| `paper_comparisons/figure678/` | Multi-figure comparison outputs for paper Figures 6-8. |
| `paper_comparisons/figure8/` | Figure 8 mechanism-resolved comparison outputs, including PNG/SVG/PDF/TIFF variants. |

Keep new generated figures in the most specific matching subdirectory rather than in this root folder.
